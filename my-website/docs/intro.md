**RussiaRoutes** — веб-приложение для планирования путешествий по России, объединяющее туристов, региональные туристско-информационные центры (ТИЦ) и Ростуризм. Платформа предоставляет каталог официальных и авторских маршрутов, конструктор для создания собственных маршрутов, возможность скачивания для офлайн-использования и механизмы модерации контента.

## Основные функции

- **Каталог маршрутов** — поиск и фильтрация маршрутов по региону, типу (пеший, водный, авто), сложности и длительности с отображением на карте
- **Детальный просмотр** — описание, фотографии, точки маршрута, оценки и отзывы пользователей
- **Создание авторских маршрутов** — конструктор с добавлением точек на карте, описаний, фото, длительности и сложности (для верифицированных авторов)
- **Модерация контента** — ТИЦ проверяют авторские маршруты, отправляют на доработку или публикуют
- **Офлайн-доступ** — скачивание маршрутов (карта, точки, описание) для использования без интернета
- **Личное хранилище** — сохранение понравившихся маршрутов в «Избранное»
