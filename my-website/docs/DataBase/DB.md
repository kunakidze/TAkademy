# Модель данных

В данном разделе представлена объектная модель данных платформы **RussiaRoutes**, обоснование выбора реляционной СУБД PostgreSQL, а также описание ключевых сущностей и их связей.

## Выбор технологии хранения данных (для MVP)

На основе анализа требований к данным для MVP принято решение использовать **реляционную СУБД PostgreSQL**. Ниже приведена таблица обоснования по каждой предметной области.

| Критерий | Пользователи | Маршруты | Достопримечательности |
| -------- | ------------ | -------- | ---------------------- |
| Объем данных | 50 000 | 100 000 | 700 000 |
| Паттерны чтения/записи данных | OLAP | OLAP | OLAP |
| Требования к консистентности | strong consistency | strong consistency | strong consistency |
| Требования к доступности | 99.9% | 99.9% | 99.9% |
| Требования к мутабельности системы | Жесткая схема | Жесткая схема | Жесткая схема |
| Требования к транзакциям | Да, критично | Да, критично | Да, критично |
| Требования к поиску и запросам | Агрегация и группировка | Агрегация и группировка | Агрегация и группировка |
| Требования к стоимости | Среднее | Среднее | Среднее |
| **Итог:** | **Реляционная СУБД PostgreSQL** | **Реляционная СУБД PostgreSQL** | **Реляционная СУБД PostgreSQL** |

## Объектная модель

### Сущность `routes` (маршруты)

Взаимодействуют: **Турист**, **Автор**, **ТИЦ**.

Региональные маршруты, доступные для изучения.

| Атрибут | Тип | Описание |
| ------- | --- | -------- |
| `creator` | object (`users`) | Автор маршрута, сущность users |
| `region` | enum | Регион, по которому построен маршрут |
| `attraction` | collection | Перечень достопримечательностей, которые представлены в маршруте |
| `name` | string | Название маршрута |
| `type` | enum | Тип маршрута, может принимать значения: `hiking`, `cycling`, `auto`, `water` |
| `description` | string | Развернутое описание маршрута |
| `duration` | enum | Указание длительности маршрута, может принимать значения: `short`, `medium`, `long` |
| `difficulty` | enum | Сложность маршрута, может принимать значения: `easy`, `medium`, `hard` |
| `photo` | array[string] | Массив с url для фото маршрута |

### Сущность `users` (пользователи)

Взаимодействует: **Администратор**.

Пользователи системы.

| Атрибут | Тип | Описание |
| ------- | --- | -------- |
| `role` | enum | Роль пользователя, может принимать значения: `tourist`, `author`, `TIC`, `admin` |
| `login` | varchar(50) | Логин пользователя, должен быть уникален |
| `password` | varchar(255) | Хешированный пароль |
| `email` | varchar(100) | Адрес электронной почты |
| `full_name` | varchar(100) | ФИО пользователя |
| `created_at` | timestamp | Дата регистрации |

### Сущность `attraction` (достопримечательности)

Используется в маршрутах (из OpenAPI-спецификации).

| Атрибут | Тип | Описание |
| ------- | --- | -------- |
| `attractionId` | integer | PK |
| `attractionName` | string | Название достопримечательности |
| `attractionDescription` | string | Описание |
| `attractionType` | enum | `museum`, `park`, `monument`, `natural`, `other` |
| `location` | GeoPoint | Координаты (lat, lon) |
| `schedule` | object | Режим работы (json) |
| `photos` | array[string] | URL фотографий |
| `region` | RegionRef | Ссылка на регион |
