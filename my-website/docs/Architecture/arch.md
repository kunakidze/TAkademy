# Архитектура системы

## Общая концепция

Платформа представляет собой **веб-приложение** с адаптивным интерфейсом (поддержка мобильных устройств) и клиент-серверной архитектурой. Основные принципы:

- **Модульность** — возможность подключать внешние сервисы (карты, системы бронирования) в будущем.
- **Масштабируемость** — горизонтальное масштабирование без изменения кода.
- **Безопасность** — ролевая модель доступа, HTTPS, хеширование паролей, соответствие ФЗ-152.
- **Офлайн‑доступ** — кэширование маршрутов на устройстве через Service Workers.

## Логическая архитектура

На основе объектной модели и требований к данным выделены следующие логические уровни:

| Уровень | Компоненты | Технологии |
|---------|------------|-------------|
| **Представления (Frontend)** | Адаптивные веб-страницы (каталог, карточка маршрута, конструктор, личный кабинет, панель модерации) | React / Vue, PWA, Service Workers |
| **Прикладной уровень (Backend)** | REST API, асинхронные обработчики (NATS), бизнес-логика, валидация, модерация | Python (Django) / Java (Spring), NATS |
| **Уровень данных** | Реляционная СУБД (PostgreSQL), кэш (опционально), объектное хранилище для фото | PostgreSQL, S3-совместимое хранилище |
| **Интеграции** | Картографический сервис (Яндекс.Карты), будущие интеграции с системами бронирования | REST API, OpenAPI |

### UML Sequence

**Sequence-диаграмма** для варианта использования «Найти маршрут по региону» показывает взаимодействие между пользователем, фронтендом, бэкендом, базой данных и картографическим сервисом.

```plantuml
@startuml

' Объявление участников процесса
actor Турист as t
participant Система as s
database "База Данных" as db
participant "<<API>>\nКартографический сервис" as m

' Описание процесса
t -> s : Название региона
s -> db : GET /region_routes

alt ok
    db --> s : 200 OK
    s --> t : Страница со списком маршрутов
else not found
    db --> s : 404 Not Found
    s --> t : По вашему запросу ничего не найдено.\nПопробуйте изменить регион или параметры поиска.
else internal server error
    db --> s : 500 Internal Server Error
    s --> t : Временная ошибка.\nПовторите позже.
end

opt
    t -> s : Отобразить маршруты на карте
    s -> m : GET /routes_at_map
    alt ok
        m --> s : 200 OK
        s --> t : Карта с указанием начала/конца маршрутов
    else internal server error
        m --> s : 500 Internal Server Error
        s --> t : Временная ошибка.\nПовторите позже.
    end
end

@enduml
